## Project Description
The **Ecommerce Product Showcase** is a web-based application that allows users to view and interact with a collection of products. Users can add products to their cart or wishlist and see a dynamic count of items in real-time. This project focuses on frontend interactivity and uses local storage to manage cart and wishlist data, making it lightweight and easy to run locally without a backend database.

## Features
- Display a collection of products with images, names, and prices.
- Add products to **Cart** and **Wishlist**.
- Real-time update of cart and wishlist count.
- Persistent data using **localStorage**.
- Responsive layout for mobile and desktop screens.
- Easy to extend with new products or features.

## Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
- **LocalStorage API** for storing cart and wishlist data.
